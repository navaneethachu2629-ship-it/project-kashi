PROJECT NOTES

Database documentation

Core entities, relationships and database concepts.

01

Entities

Customer stores people. Branch stores branch details. Employee stores staff. Account stores account type, status and balance. Account Holder connects customers to accounts. Bank Transaction is the ledger. Loan stores loan applications and Loan Payment stores payment records.

02

Cardinality

  • Branch 1:M Account
  • Branch 1:M Employee
  • Customer M:N Account through Account Holder
  • Account 1:M Bank Transaction
  • Customer 1:M Loan
  • Branch 1:M Loan
  • Loan 1:M Loan Payment
03

DBMS concepts

PK: uniquely identifies a row. FK: links related tables. Constraint: protects data quality. View: saved query for easier reading. Trigger: automatically adjusts balance after a successful ledger insert. Stored function: returns a value. Stored procedure: runs a parameterized query.

04

Workflow

  1. HTML form collects input.
  2. Flask validates the request.
  3. Connector sends SQL to MySQL.
  4. MySQL constraints and trigger run.
  5. Flask shows success/error feedback.
For your report: open docs/DATABASE_DOCUMENTATION.md, docs/ER_DIAGRAM.md and queries.sql in the project folder.
